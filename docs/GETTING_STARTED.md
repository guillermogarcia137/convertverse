# Empezar con ConvertVerse

Abre https://guillermogarcia137.github.io/convertverse/ y elige un archivo o arrástralo a la página. Selecciona el formato de salida, pulsa **Convertir todo** y descarga el resultado. Puedes convertir varios archivos y descargarlos juntos en un ZIP.

Los accesos rápidos preparan DOCX → PDF, PNG → ICO, ICO → PNG, JPG → WebP y WAV → MP3. En **Probar con un archivo de ejemplo** hay pequeños documentos sintéticos para comprobar el funcionamiento sin usar archivos personales.

El botón **Temas** abre 42 estilos con vista previa. Puedes buscar, filtrar y cambiar de tema; se recuerda en ese navegador. Cada aplicación conserva sus preferencias por separado.

Los archivos se procesan en el dispositivo del visitante, dentro de la web. No hace falta instalar ConvertVerse, mantener un ordenador encendido ni iniciar sesión. Los motores pueden necesitar una descarga grande la primera vez.

DOCX → PDF recompone el contenido y puede variar la maquetación. Guarda los antiguos `.doc` como `.docx` primero. Las combinaciones disponibles dependen del formato, códec, navegador y memoria del dispositivo.

Para desarrollar o publicar cambios, consulta [README.md](../README.md). Los demás documentos de esta carpeta proceden de VERT y describen opciones del proyecto original; los servicios externos están desactivados en esta versión.
