# Contribuir a ConvertVerse

Este repositorio adapta VERT. Para trabajar en esta versión, sigue [README.md](README.md): Node.js 24, Bun 1.4.4 y configuración pública en `.env.example`.

Antes de proponer un cambio, ejecuta `bun run check`, `bun run test` y `bun run build`. Prueba las conversiones afectadas con archivos sintéticos; no añadas documentos personales, credenciales ni archivos convertidos al repositorio.

Conserva la licencia AGPL-3.0 y los créditos de VERT. Los recursos del proyecto original y su documentación se encuentran en [UPSTREAM.md](UPSTREAM.md). Las contribuciones dirigidas al proyecto VERT original deben respetar sus propias normas.
